2. Send all 32 images to yourself in Telegram (Saved Messages) as PHOTOS (not as files),
   with the HD option switched ON if Telegram shows it. Then save them back from Telegram.
   This shrinks them and strips any leftover metadata. Keep the file names / ad IDs straight
   (send one ad at a time: S1 4x5, S1 9x16, then S2 ...).
3. Check a saved 9x16 image is still sharp. If Telegram made it blurry, use the original from the zip instead.

- Advantage+ campaign budget (CBO): OFF. Budget is set per ad set.
- Special ad categories: none. A/B test: off.

Same settings in every ad set:
- Conversion location: Website. Pixel: BetFriend pixel.
- Budget: Daily $45. Schedule: start tomorrow 12:00 AM (account time zone), no end date.
- Location: United States. People living in or recently in this location.
  (If Meta's gambling authorization lists specific states, target only those states.)
- Age: 21 to 65+. Gender: all. Languages: English (All).
- Detailed targeting: none. Custom audiences: none. Lookalikes: none. (Broad. Advantage+ audience ON is fine,
  but keep the minimum age at 21 under "audience controls".)
- Placements: choose MANUAL placements (not Advantage+). Devices: All. Platforms: Facebook + Instagram only.
  Tick ONLY these 4:  Facebook Feed · Instagram Feed · Facebook Reels · Instagram Reels.
  Untick everything else: Stories, Explore, Search, Marketplace, Right column, Video feeds, Notifications,
  Profile feed, In-stream, Ads on Reels / overlay ads, Messenger and Audience Network.
- Attribution: 7-day click, 1-day view (default).

STEP 4 · ADS (each ad set gets the 4 ads listed above)
- Identity: BetFriend Facebook page + BetFriend Instagram account.
- Ad setup: Create ad · Single image. Ad name = the ad ID (e.g. "S1").
- Media: upload both sizes and use placement asset customization:
    Facebook Feed + Instagram Feed = 4x5 image · Facebook Reels + Instagram Reels = 9x16 image.
  Check the preview for all 4 placements: no text should be hidden behind the Reels buttons or caption.
- Copy: paste the Primary text, Headline, Description, Call to action and Website URL EXACTLY as below.
  All links go to https://betfriend.bet. Display link (if asked): betfriend.bet
  Do not rewrite or shorten anything. Keep the {{site_source_name}} part of the URL as it is.
- Turn OFF ALL creative enhancements (this is very important). In the ad, open "Advantage+ creative" /
  "Creative enhancements" and switch OFF every item, including: text improvements / text generation,
  visual touch-ups, image brightness & contrast, image expansion / expand image, image templates,
  add overlays, music, 3D animation, enhance CTA, relevant comments, add site links,
  add catalog items, image animation, translate text, and "Show summaries". Also turn OFF
  "Multi-advertiser ads" and "Dynamic creative". Check this again on EVERY ad (Meta turns some on by default).
- Tracking: Website events = BetFriend pixel ON.

STEP 5 · BEFORE YOU STOP
- Every ad shows the 21+ line in the image. Do not crop it out.
- Leave the whole campaign in DRAFT. Send the owner a message: "BetFriend campaign drafted, ready for review"
